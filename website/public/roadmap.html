Getting better

02

Ongoing refinement and validation. No fixed delivery dates.

Less work in the background

Continue measuring resource use, refining visible-widget sampling, animations and indexing.

More desks, more displays

Broader real-world checks for mixed DPI, monitor hotplug, fullscreen games and graphics drivers.

A smoother first launch

Trusted code signing, clean Windows machine testing, startup behavior and accessibility coverage.

More players, fewer surprises

Expand physical media-player and device checks, keyboard and screen-reader testing.
