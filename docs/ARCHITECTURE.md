# Architecture

Nagi 1.9 adds WelcomeWindow, shared vertical/horizontal DockLayout, optional WeatherService, a measured MusicVisualizer and speaker routing. See [setup and implementation details](WELCOME-AND-LAYOUT.md).

Battery status is sampled with system metrics through Win32 `GetSystemPowerStatus`. `PowerSnapshot` decodes charge flags and unknown/no-battery sentinels; the view model exposes percentage/details without substituting a fake value. The compact logo supports a six-DIP drag threshold while retaining ordinary pin/expand clicks.

Lua UI customization is evaluated in `Pulse.Infrastructure/LuaUiService.cs` using embedded MoonSharp and returns a validated `LuaUiStyle`. The interpreter receives only theme/profile strings, uses a restricted library set, and has source/instruction limits. `Pulse.App/LuaUi.cs` evaluates off the UI thread, ignores superseded results, applies theme resources and presentation properties, and retains the last working appearance after errors. Scripts cannot obtain native controls or call tray, launch, media or audio services. See [LUA-UI.md](LUA-UI.md).

Nagi is an unpackaged, self-contained WinUI 3 application targeting Windows 11 x64. The installed .NET 10 SDK and stable Windows App SDK 1.8.260921001 were selected, with its required SDK BuildTools 10.0.26100.4654. These are exact package references, not floating versions.

`App` holds a per-session named mutex and activation event. A second process signals the first and exits. One `MainWindow` is reused for compact, expanded and detailed settings/profile views. Closing the window cancels polling, unregisters the hotkey and detaches the native subclass.

The composition root constructs services against Core interfaces. `PulseViewModel` is the shared state for all views. A sequential background task samples CPU/memory, foreground identity and media, then dispatches a snapshot to the UI queue. No overlapping poll ticks accumulate. Windows media calls receive cancellation with a three-second deadline. Audio runs in a separate cancellable 50 ms loop with at most one queued dispatcher update. Volume changes are throttled to 50 ms and executed on a worker thread. Artwork is bounded to 2 MB, retried after two seconds when missing, and refreshed every 15 seconds for unchanged tracks; identical bytes retain the decoded image.

The context engine knows only application identities, settings and time. Priority is manual lock, matching rule ordered by descending priority, then fallback. Equal priorities retain list order. A candidate profile must remain selected for 1.8 seconds; a different candidate resets the timer. Nagi's own foreground window does not replace the user's previous context. Manual selection applies immediately. Fullscreen is exclusively a visibility signal.

JSON settings are serialized through a semaphore and written to a same-directory temporary file. `File.Replace` atomically commits with a previous-file backup. Known fields are decoded individually; malformed fields fall back without resetting valid siblings. Unknown top-level fields survive. Schema 0 is normalized to 1; schema >1 is readable but cannot be overwritten. Recovery copies protect malformed input. Settings commits on the UI are serialized; a new immutable settings snapshot is passed to polling through `Volatile.Write`.

CPU uses deltas of `GetSystemTimes`, whose kernel counter includes idle time. The first sample is unavailable until a second measurement. RAM uses `GlobalMemoryStatusEx`. Network uses per-interface byte deltas and monotonic elapsed time; interfaces added or reset cannot produce negative spikes. Foreground identity uses `PROCESS_QUERY_LIMITED_INFORMATION` and never reads document titles. Media uses `GlobalSystemMediaTransportControlsSessionManager`. Audio caches the current default render endpoint and optional IAudioMeterInformation, probes for endpoint changes every 500 ms, serializes access with a lock, checks HRESULTs, and releases COM objects deterministically on shutdown. Peak readings are normalized system signal activity before endpoint attenuation; no PCM is captured.

Window sizing uses monitor work areas and DPI-scaled logical sizes. Anchors plus logical offsets preserve placement. Monitor removal falls back to the primary display and clamps the whole window to its work area. A native subclass handles hotkeys, display/DPI changes and completed drag moves. The compact window declines activation on ordinary clicks. Only explicit expansion calls `Activate`. No click-through window styles are used. Borderless `OverlappedPresenter`, native acrylic, DWM corner rounding, a Win2D antialiased fill and tool-window styling provide Nagi behavior. Custom polygon window regions are no longer used.

The app reads fullscreen state during polling, using the actual foreground sample for visibility and retaining the last non-Nagi application for profile context. Hotkey reveal overrides fullscreen hiding until dismissal or a foreground application change. Focus suppresses nonessential notices inside Nagi; it does not alter Windows notifications. No Windows service is installed. A native tray icon, either shortcut, or a second launch can recover a deliberately hidden Nagi.

## Design tokens

`Themes/Tokens.xaml` defines surfaces, text, accent and inset layers for Akeno, dark, light and high contrast. Cards default to radius 18; the Nagi surface uses radius 22. Typography uses Windows' native UI font. The vertical rail is 80×420 DIP, the resting tab 18×132, and a hover frame is 430 DIP wide. Expanded overview frames are 580×780 and detailed frames 720×800, clamped to the work area. The 80-DIP rail stays beside inward-opening content. Metric graphs contain only real samples.

`HaloAcrylicBackdrop` owns a native thin DesktopAcrylicController. It keeps the compact utility's material active without taking keyboard focus, while retaining Windows' transparency, contrast and power policy. Palette changes update tint, luminosity and fallback colors. Disconnect disposes the controller.

`HaloMotion` drives native bounds from closed-form critically damped springs and retains velocity when retargeted. Content opacity, scale and button springs run through the Windows compositor. Expanded content is measured at its destination size to prevent text reflow during a window morph. Native animation ticks run only during transitions and are stopped at rest/shutdown. Reduced-motion settings snap to the same final layout.

`SystemTrayService` uses Shell_NotifyIcon, a separate native subclass, version-4 shell callbacks and a native accessible context menu. Its identity is stable for a given executable path, avoiding GUID path-binding problems with unsigned portable builds. It re-registers on TaskbarCreated and deletes the icon before releasing its HICON. WM_COMMAND handling supports native accessibility clients as well as pointer/keyboard selection. The three hotkeys (panel, hide/show and quick search) use separate pairs of IDs so conflicts preserve each previous registration.

## Engineering assumptions

- An unpackaged portable folder plus per-user PowerShell installer is practical without certificates or Store identity.
- Foreground polling is sufficient for MVP context detection; process-start event subscription would add complexity without changing the foreground-only rule policy.
- Built-in profile identities are fixed; users customize application mappings and per-profile shortcuts. Arbitrary profile creation is a later milestone.
- GPU and microphone integrations use native Windows providers. Temperatures require a supported WMI sensor provider, FPS requires tracing permission, and OBS requires its local WebSocket server. Unavailable data stays explicit.
- UI code-behind owns Windows lifecycle and editor construction; context policy and persistence remain independently testable.

Official references: [unpackaged WinUI deployment](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/unpackage-winui-app), [system backdrops](https://learn.microsoft.com/en-us/windows/apps/develop/ui/system-backdrops), [Windows App SDK releases](https://github.com/microsoft/WindowsAppSDK/releases), [Core Audio volume](https://learn.microsoft.com/en-us/windows/win32/api/endpointvolume/nf-endpointvolume-iaudioendpointvolume-getmastervolumelevelscalar), [Windows media controls](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssession.trytoggleplaypauseasync).

## Edge interaction

`Pulse.Core/DockInteraction.cs` owns resting, compact and expanded stages plus pin state. `Pulse.App/EdgeDock.cs` applies pointer dwell, departure and explicit-click behavior. `HoverPreview.cs` retains CPU/media details within the compact stage. `HaloFrame.DropAmount` remains a sixth spring component of the resting/reveal transition; `HaloWindowManager` positions the frame against the selected screen edge, while Win2D and DWM render its surface and corners. Both XAML and Win32 dialog-frame borders are removed. Native menu opening settles the owner before entering its modal loop. The position model normalizes older anchors to Left edge or Right edge, and dragging persists the nearest edge and vertical offset.

Akeno applies a host-owned ink/red palette before optional Lua colors; High Contrast retains system resources. A cached AccessibilitySettings object is checked during regular UI refresh because event registration can fail in unpackaged hosts. Vertical previews open inward while preserving the rail center, with height clamped to the work area. Native frame caching skips redundant positioning calls. A tighter dimensionless spring tolerance prevents final geometry jumps. EdgePreviewSizing retains helpers and regression coverage for preview sizing.

Quick search is owned by MainWindow in Launcher.cs with one reusable QuickSearchWindow. A third independently registered hotkey triggers it. Core QuickSearch ranks immutable entries and evaluates a bounded arithmetic parser. Windows SearchApplications reads/opens the live Applications shell folder on an STA worker and releases COM references. Infrastructure FileSearchIndex scans metadata on workers, limits roots/entries, skips linked/system/build folders, persists a local cache and honors cancellation. Refreshes serialize behind the previous task; scope changes immediately clear old results and cached entries must match the selected roots. Query generations prevent stale results replacing newer input. Launches require a selected action and retain file/URL validation; clipboard access writes only on an explicit copy action. No clipboard history or query history is collected.

Nagi 1.8 uses an 80×420 DIP vertical rail (scrollable on short work areas), an 18×132 resting tab, and inward-opening 350-DIP previews. DWM owns native corner rounding with no window-region polygon; Win2D CanvasGeometry draws the antialiased fill without an outer stroke. The rail remains available beside expanded detail panels. Hardware/studio sampling has its own cancellable worker, independent of the 50 ms output-audio loop. GPU PDH counters are cached; sensor WMI queries are throttled. Core Audio capture endpoints control the default communications microphone without recording. PresentMon uses unique bounded timed traces, disables input tracking and can read a fresh external helper snapshot. OBS uses bounded local WebSocket v5 sessions, protocol authentication and observed output-state changes. Credentials are DPAPI-protected outside JSON settings.
