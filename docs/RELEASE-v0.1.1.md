# Nagi v0.1.1

A glass desktop companion for Windows 11. Your apps, music and useful information, tucked into the edge of your screen.

The release is named **Nagi** and uses the **`v0.1.1`** tag. See the [v0.1.1 changelog](../CHANGELOG.md), [app guide](USER-GUIDE.md), and [dock/teardrop screenshots](WELCOME-AND-LAYOUT.md#teardrop-dock-and-app-folder).

Quick fixes: switching Akeno → Light or day/night themes no longer crashes the acrylic configuration handler. The resting teardrop no longer has a rounded glass pill behind it; its native shape owns clipping instead of forced Windows rounding. The open dock retains acrylic.

Includes the empty Default profile (search, CPU/GPU, now playing), Work/Gaming presets, Stream profile, optional mic/weather/battery, OBS hover recording/streaming and three scenes, single-line apps with four per row and an expanding dock folder, preferred music-service fallback links, and automatic update downloads with Settings → Updates → Install and restart.

This is an early v0.1.x release. v1 will wait for the owner's approval.

Downloads: **Nagi-Portable.exe** for direct launch, **Nagi-win-x64.zip** for an extracted portable folder, or **Nagi-Setup.exe** for a per-user installation. SHA256 checksums accompany every package. Windows 11 22H2 or newer, x64; runtimes are included. The app and wrappers are unsigned.
